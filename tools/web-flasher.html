Write the firmware to an ESP32-S3 from the browser, no toolchain to install.

Device

Chip— Flash— MAC—

The browser cannot reset the chip over the native USB port (USB‑JTAG / MicroPython CDC), so enter download mode by hand first: hold BOOT, tap RESET, then release BOOT. A UART bridge with the DTR/RTS auto-reset circuit does not need this step.

Images (click to choose a file; rows without one are not written)

Per-partition images (advanced)
Flash 16MB; the read/write mode comes from each image

Both flashing options rebuild the app filesystem partition, so the data under /config (WiFi settings), /data and /skills is erased; app-fs.bin only leaves the bootloader and model partitions alone. To update the app on a device that is already configured, use Firmware Update (OTA) in the WebUI — it replaces /app only.

Flash Complete

  1. If the device did not restart, press the RESET button on the board: the browser can only reset the chip through the RTS line, which the native USB port does not carry, so the chip stays in download mode.
  2. The images carry no WiFi credentials, and a wired flash clears the settings already on the device. Once it boots, it opens the setup hotspot EdgeAgent-Setup (no password, for about 5 minutes); joining it usually opens the setup page in your browser by itself — if it does not, use the button below.
